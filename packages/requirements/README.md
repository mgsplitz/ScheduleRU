# Requirements

Requirement progress, course allocation, reviewed selector matching, and
academic-credit equivalency closure live here. The program-requirement model
owns shared-Core normalization, display-family deduplication, and reviewed
double-count analysis across selected programs. The requirement-tree builder
normalizes reviewed API roots into course/group engine inputs, including
metadata merging and conservative prerequisite IDs. This package owns no UI,
four-year placement policy, network access, or catalog content.

The modules currently expose browser globals for compatibility. Root-level
files are imports only.
